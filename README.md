# Craft & Beer API (FastAPI + MongoDB)

API REST asíncrona desarrollada en Python utilizando FastAPI, Motor y Pydantic para la gestión de ítems y productos de la cervecería Craft & Beer.

## Requisitos PrPrevios
- Python 3.10 o superior
- Instancia de MongoDB ejecutándose localmente en `mongodb://localhost:27017`
